# Security Policy

## Reporting a Vulnerability

Please do not disclose vulnerability details in a public issue or discussion. If private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a report.

If private reporting is unavailable, ask a maintainer for a private reporting channel without sharing sensitive details publicly. Include the affected component or commit, impact, reproduction steps, and any suggested mitigation in the private report.

There is no published response-time commitment. Reports concerning the current default branch are welcome.
